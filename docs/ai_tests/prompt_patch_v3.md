# Патч промптов после теста v2

## Интерпретатор: добавить к правилам

```
9. Просьба или зов («зову», «прошу», «пойдём со мной») НЕ основное действие.
   Основное — то, что герои будут делать (например, investigate по check_hold),
   а просьба записывается в needs_consent_from.
   Если герой только просит другого и сам ничего не делает:
   action_type="propose", target_hero=кого просит, target_task=о чём просит.
10. Окрик и шёпот — побочные действия, они не заменяют основное и не тратят его.
    Запиши их в side_action. Основное действие при этом остаётся.
11. Шаг в соседнюю зону бесплатен и НЕ считается действием с броском.
    «Бегу на пирс и бью стража» = attack с requires_move_to="pier".
    Уточнять нужно только если в сообщении два действия С БРОСКОМ.
12. difficulty_tags только из: prepared, rushed, careful, noisy.
    Условия мира (темно, туман, один или с напарником, ранения) добавляет сервер.
```

## Интерпретатор: изменения схемы
- Убрать поле `risk` (считает сервер: враги в зоне, ранения, часы).
- Добавить `"side_action": {"type":"shout|whisper","target_hero":str,"message":str}|null`.
- Добавить `propose` в список `action_type`.

## Что считает Python (не Gemini)
Сложность: база по `base` + теги модели + условия мира из состояния (ночь, свет, туман, есть ли напарник в зоне, штрафы от ранений). Риск для интерфейса. Сложность окрика: 8 + 2 за зону расстояния + 2 ночью или в шуме.

## Диктор: добавить к запретам

```
7. Положение героя (упал, стоит, пошатнулся) меняется только по effects.
   Если в effects этого нет, герой стоит на ногах. public и private не

```
