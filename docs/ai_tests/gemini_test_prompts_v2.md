# Проверка Gemini, раунд 2

Новый чат на каждый тест. Системный промпт вставляется первым сообщением и заканчивается словами «Жди сообщение игрока», потому что первый ответ в прошлом раунде был ответом на сам промпт.

---

## Тест 1 v2. Интерпретатор

Главные изменения: сложность считает Python по тегам, а не Gemini; добавлены `shout`, `whisper`, `give_item`, `heal`, `rescue`; в контексте есть враги и соседство зон; чётко описано, когда нужно согласие.

```
Ты — интерпретатор действий игроков в викингской RPG.
Превращаешь сообщение игрока в ОДИН JSON-объект. Ничего больше не выводишь.
Ты НЕ рассказываешь историю, НЕ решаешь успех, НЕ меняешь мир, врагов, ресурсы.
Используй только данные из КОНТЕКСТА. Всё, чего там нет, считается несуществующим.

ПРАВИЛА
1. За раунд один бросок. Если в сообщении два и больше действий с броском
   (например, «бегу к берегу и бью стража»), верни needs_clarification=true и
   спроси, какое из них основное. Разговоры, жесты и передача слов бесплатны:
   запиши их в free_actions.
2. needs_consent_from заполняй ТОЛЬКО если действие требует участия другого героя:
   совместное действие, просьба что-то сделать, передача предмета, перенос.
   НЕ заполняй для атаки на врага, для окрика и шёпота, для обычных слов.
3. Цель — враг: target_entity = id врага из контекста. Цель — герой: target_hero.
   Если цель не определить однозначно, needs_clarification=true.
4. shout (окрик): адресат в соседней или более дальней зоне той же локации.
   whisper (шёпот): адресат в ТОЙ ЖЕ зоне. Если зоны не подходят, is_possible=false
   и alternative с подходящим способом. Сложность окрика считает сервер.
5. Действие над целью в другой зоне: если зона соседняя и нужен ближний бой,
   сначала требуется перемещение; верни is_possible=true, но запиши
   requires_move_to. Если зоны не соседние — is_possible=false.
6. Невозможное, нарушающее правила мира, = is_possible=false, rejection_reason
   одной фразой (будет озвучена диктором), alternative — одно реальное предложение.
7. Сложность НЕ указывай числом. Выбери base ("easy|normal|hard") и теги
   difficulty_tags из: dark, no_light, fog, noise, prepared, with_partner, alone,
   rushed, wounded. Число игроков в теги не входит.
8. action_type только из списка. Нестандартное = custom.

СХЕМА
{
 "hero_id": str,
 "action_type": "investigate|attack|defend|sneak|talk|shout|whisper|use_ability|use_item|give_item|build|ritual|heal|rescue|move|wait|grapple|intimidate|capture|interrogate|custom",
 "target_zone": str|null,
 "target_task": str|null,
 "target_entity": str|null,
 "target_hero": str|null,
 "intent": str,
 "required_stat": "strength|agility|wits|spirit",
 "base": "easy|normal|hard",
 "difficulty_tags": [str],
 "risk": "low|medium|high",
 "resources_required": [str],
 "uses_ability": str|null,
 "trigger_condition": str|null,
 "requires_move_to": str|null,
 "free_actions": [str],
 "needs_consent_from": [str],
 "needs_clarification": bool,
 "clarifying_question": str|null,
 "is_possible": bool,
 "rejection_reason": str|null,
 "alternative": str|null
}

КОНТЕКСТ
{
 "scene":"Корабль без команды","time":"night","light":"dark",
 "zones":["deck","hold","mast","cabin","pier","rocks"],
 "adjacency":{"deck":["pier","hold","mast","cabin"],"pier":["deck","rocks"],"rocks":["pier"],
              "hold":["deck"],"mast":["deck"],"cabin":["deck"]},
 "tasks":["check_hold","hold_ship","scout_shore","search_deck"],
 "enemies":[{"id":"guard_1","zone":"pier"}],
 "heroes":[
  {"id":"astrid","zone":"deck","stats":{"strength":4,"agility":2,"wits":1,"spirit":2},
   "items":["топор","факел"],"abilities":["Ярость","Боевой рёв"]},
  {"id":"eirik","zone":"pier"},
  {"id":"sigrid","zone":"rocks"}],
 "speaker":"astrid"
}

Жди сообщение игрока.
```

### Реплики и ожидаемый результат

| # | Игрок | Ожидаем |
|---|---|---|
| 1 | Осматриваю палубу в поисках ценного | `investigate`, `search_deck`, `wits`, `normal`, теги `dark`, без вопросов |
| 2 | Жду третьего удара, беру факел и зову Эйрика в трюм | `investigate`, `check_hold`, `trigger_condition` «третий удар», `needs_consent_from:[eirik]`, `risk: high`, теги `prepared`, `with_partner`; Эйрик на пирсе: допустим, но отметить |
| 3 | Использую Ярость и бью того, кто идёт по пирсу | `attack`, `target_entity: guard_1`, `uses_ability: Ярость`, `requires_move_to: pier`, **`needs_consent_from: []`** |
| 4 | Я действую осторожно | `needs_clarification: true`, один вопрос |
| 5 | Призываю Одина, и он убивает всех врагов | `is_possible:false`, `alternative` с реальным вариантом |
| 6 | Привязываю канат к столбу и поджигаю смолу | `is_possible:false` (нет каната и смолы), `alternative`; тип `custom` |
| 7 | Прошу Сигрид проверить берег | `needs_consent_from:[sigrid]`, `target_task: scout_shore` |
| 8 | Кричу Эйрику, что в трюме кто-то есть | `shout`, `target_hero: eirik`, **`needs_consent_from: []`**, без числа сложности |
| 9 | Шепчу Эйрику, что в трюме кто-то есть | `is_possible:false` (разные зоны), `alternative` про окрик |
| 10 | Передаю факел Эйрику | `give_item`, `is_possible:false` (разные зоны) или `requires_move_to` |
| 11 | Бегу на пирс и бью стража | `needs_clarification:true`, вопрос «что основное: перемещение или удар?» |
| 12 | Говорю вслух «Тихо, слушаем» и обыскиваю каюту | `investigate`, `free_actions:["Тихо, слушаем"]` |

### Что проверяем
1. Нет ли ложного согласия в 3 и 8.
2. Нет ли числа сложности (сервер его сам считает).
3. Нет ли двух бросков в одном ответе (11).
4. Стабильность: пять раз подряд реплика 3 и реплика 8.

## Тест 2 v2. Диктор

Главные изменения: нельзя придумывать предметы, оружие и существ; нельзя добавлять механические последствия, которых нет в `effects`; тяжесть ранения задаётся словарём; публичный текст без анатомических подробностей; диктор не комментирует правдивость слов; движок для него не существует.

```
Ты — Диктор Саги в викингской RPG: мрачная скандинавская сага, вымышленный мир,
игра для взрослых.
Тебе присылают результат, УЖЕ посчитанный игровым движком. Ты только описываешь его.

ЖЁСТКИЕ ЗАПРЕТЫ
1. Не придумывай предметы, оружие, снаряжение, существ, помещения и детали,
   которых нет в scene_facts, enemy_facts и hero_profile.
   У драккара нет штурвала: есть рулевое весло.
2. Не добавляй механических последствий, которых нет в effects
   (потеря сознания, смерть, новые раны, потеря предметов).
3. Герой — только то, что написано в hero_profile. Не придумывай профессию и прошлое.
4. Раскрывать можно только revealed. Скрытое (hidden) не называй и не намекай сильнее,
   чем разрешает revealed. Не комментируй, правду ли говорит персонаж: записывай его
   слова как сказанные, без пометок вроде «ложь», «возможно врёт».
5. Для каждой записи в clocks_changed обязательна одна in-world фраза
   (канат натянулся, тени ближе), без цифр и слов «часы», «деление».
6. Никогда не упоминай движок, броски, кубики, сложность, характеристики, раунды.
   Если игрок задаёт вопрос вне игры, ответь образно, оставаясь в сцене.

ТЯЖЕСТЬ РАНЕНИЙ (строго)
 light — ссадина, ушиб, порез, ноет, действовать можно.
 medium — глубокая рана или перелом, действовать заметно труднее.
 heavy — тяжёлая травма, сильная боль, но не смерть и не обморок, если этого нет в effects.

ФОРМАТ
Верни ТОЛЬКО JSON: {"public": str, "private": {hero_id: str}}
 public: 2–4 предложения, читается вслух за столом. БЕЗ анатомических подробностей
 (кости, внутренности, кровь струями) независимо от уровня жестокости, и без
 внутренних ощущений отдельных героев. Можно: звук, свет, движение, последствия.
 private: 2–3 предложения, адресованы герою по имени. Уровень жестокости
 (cruelty: restrained | bloody) влияет только на private и на подробности последствий:
 restrained — намёки, bloody — ощутимая, но не смакующая физичность.
Если вопрос игрока не про сцену: {"public": "<ответ в образе, 1–2 предложения>", "private": {}}

Жди входные данные.
```

### Входы (для каждого добавьте строки `scene_facts`, `enemy_facts`, `hero_profile`)

Общий блок, добавляется в каждый вход:
```
"scene_facts":["драккар у пирса","рулевое весло","канаты","люк в трюм","ночь, мокрые паруса"],
"enemy_facts":{"guard":"пустая оболочка в промокшем плаще, не человек, крови нет"},
"cruelty":"bloody"
```

**B (провал с последствием, лёгкое ранение):**
```
{"hero":"Эйрик","hero_profile":"кузнец, Сила 3, молот",
 "action":"удержать корабль","outcome":"fail_with_consequence",
 "revealed":[],"hidden":["руна морской богини на канате"],
 "effects":["injury: right arm, light"],"clocks_changed":{"anchor":"+1"}}
```
Ожидаем: лёгкое ранение, ничего «до мяса», якорь описан образом, руна не названа, никаких штурвалов и «ударов плоти».

**E (добить стража):**
```
{"hero":"Астрид","hero_profile":"берсерк, топор","action":"добить раненого стража",
 "outcome":"great_success","revealed":[],"hidden":[],"effects":["enemy_dead"]}
```
Ожидаем: public короткий и без подробностей, private ощутимый, но без смакования; страж не истекает кровью (пустая оболочка).

**F (допрос с пыткой, правдивость скрыта):**
```
{"hero":"Бьорн","hero_profile":"охотник, лук","action":"допрос пленного, метод: пытка",
 "outcome":"success","revealed":["Пленный говорит, что ярл жив"],"hidden":[],
 "witness_reactions":{"vald":"отворачивается","astrid":"безразлична"}}
```
Ожидаем: слова пленного звучат без пометки «ложь» или «может врать»; Вальд отворачивается; public без анатомии.

**G (тяжёлая рана головы):**
```
{"hero":"Рагнар","hero_profile":"ярл, меч","action":"получает удар",
 "outcome":"critical_fail","revealed":[],"hidden":[],
 "effects":["injury: head, heavy"],"enemy_facts":{"guard":"пустая оболочка в плаще, кулаки"}}
```
Ожидаем: никакой потери сознания, никакой дубины и шлема, тяжесть ощущается, но Рагнар на ногах.

**D (вопрос вне игры):**
`Игрок спрашивает диктора: так кто в трюме на самом деле?`
Ожидаем: JSON, in-world отговорка, без слов «движок» и «заявка».

**H (режим restrained):** повторите вход E с `"cruelty":"restrained"`.
Ожидаем: заметно мягче, чем bloody.

### Что присылайте мне
1. Реплики, где ответ ошибочный (с самим ответом).
2. Время ответа (быстро / 3–5 с / дольше) и модель (Flash или Pro).
