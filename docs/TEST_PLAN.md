# План тестирования

Приоритеты: **P0** обязательно до первого вечера с живыми людьми, **P1** до релиза MVP, **P2** улучшения.
Статус «готово» значит, что тест уже есть в `tests/` и проходит (`python -m pytest`).

## Уровни и инструменты
| Уровень | Инструмент | Что проверяет |
|---|---|---|
| Юнит (чистые правила) | pytest, hypothesis (по желанию) | `engine/*` без ввода-вывода |
| Данные | pytest, pyyaml | героев и сценарии |
| Интеграция сервера | pytest-asyncio, httpx, `TestClient`, WebSocket-клиенты | API, события, фильтрация |
| Контракт ИИ | pytest с подменой Gemini (записанные ответы), плюс отдельный «живой» прогон | схемы, повторы, запасной режим |
| Сценарные симуляции | боты-игроки на WebSocket | вечер целиком на 2, 4, 6, 10 игроков |
| Нагрузка | скрипт из 10 клиентов | задержка и стабильность |
| Ручная приёмка UI | чек-лист | экраны, карта, звук, телефоны |

Общие требования: кубик подменяется через `dice.py` (в тестах фиксированные значения), время подменяется, ИИ подменяется записанными ответами, база создаётся в памяти.

## U. Ручная приёмка интерфейса (чек-лист)
- Стол: большая прорисованная карта, нет подписей зон, туман по уровням, токены с аватарками, стопка «×N» при 4+ героях, не больше 4 плиток, баннер «Отряд разделён».
- Часы: три стадии, безымянные кольца до разведки.
- Общая карта: слух тёмным силуэтом с названием, подробности после посещения, масштабирование.
- Рука: «Вид» меняется по уровню раскрытия, лента, подсказки только из известного, ночной режим читаемый, силуэт ранений, окно реакции в бою.
- Кат-сцены: голос и субтитры, пропуск большинством.
- Звук: кнопка «Включить звук», эмбиент и эффекты только на Столе.
- Сохранение: значок мигает после автосохранения, меню на Столе.
- Запасные значки при отсутствии файла (временно удалите файл и проверьте).

## Как запускать
`pip install -r requirements.txt` и `python -m pytest`. Тесты из разделов R, H, C уже в проекте и проходят. Остальные разделы пишутся по мере появления кода; каждому тесту дайте имя вида `test_V_01_...` для связи с планом.
